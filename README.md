# 🩺 سایت مطب مامایی — زهره بصارت

سایت کامل و ریسپانسیو برای **مطب خانم زهره بصارت** (کارشناس مامایی در خمینی‌شهر) با قابلیت **رزرو آنلاین نوبت** و ارسال پیامک تأیید.

🔗 **دمو زنده:** [(https://fereshteh-sadeghi.ir/)]

---

## ✨ ویژگی‌های اصلی

- طراحی کاملاً موبایل‌فرست و مدرن
- سیستم رزرو نوبت چندمرحله‌ای (انتخاب روز → ساعت → اطلاعات بیمار)
- ارسال پیامک تأیید نوبت (SMS.ir / کاوه‌نگار)
- پنل مدیریت نوبت‌ها
- بخش خدمات، درباره پزشک، سوالات متداول
- سئو محلی برای کلمات کلیدی مثل «ماما خمینی‌شهر»
- طراحی با هویت بصری صورتی و حس گرم و حرفه‌ای

---

## 🛠 تکنولوژی‌ها

| بخش              | تکنولوژی                  |
|------------------|---------------------------|
| فرانت‌اند        | Next.js 16 + React 19     |
| استایل           | Tailwind CSS              |
| دیتابیس          | PostgreSQL + Prisma       |
| احراز هویت       | NextAuth                  |
| پیامک            | SMS.ir / Kavenegar        |
| فونت             | Vazirmatn                 |

## 🚀 نحوه اجرا

```bash
# کلون کردن پروژه
git clone https://github.com/Erfan1112s/dr-web.git
cd dr-web/clinic-project

# نصب پکیج‌ها
npm install

# تنظیم متغیرهای محیطی
cp .env.example .env
# سپس مقادیر را پر کنید

# اجرای دیتابیس (اگر از Docker استفاده می‌کنید)
docker-compose up -d

# اجرای پروژه
npm run dev
